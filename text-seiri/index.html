テキスト整形ツール

貼り付けるだけで、重複行の削除・並べ替え・空白と空行の除去をまとめて実行します。入力した内容は送信されません。

整形オプション

入力 0 行 → 出力 0 行

使い方

上の欄にテキストを貼り付け、必要なオプションを選ぶと、下の欄に結果がすぐ表示されます。結果は「結果をコピー」で取り出せます。処理は、空白の処理、空行の削除、重複の削除、並べ替えの順に行います。

重複行の削除
同じ内容の行が複数あるとき、最初に出てきた行だけを残します。名簿やメールアドレス、キーワード一覧の整理に使えます。
連続する空白を1つにする
半角スペース、タブ、全角スペースが続いている部分を、半角スペース1つにまとめます。
並べ替え
日本語の読み順を基準に並べ替えます。漢字は読みではなく文字コード順に近くなる場合があります。

入力したテキストはお使いのブラウザの中だけで処理され、サーバーには送信されません。
